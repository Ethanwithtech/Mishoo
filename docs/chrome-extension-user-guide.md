# Mishoo / 咪咻 Chrome 插件用户操作文档

这份文档面向普通用户，说明如何获取、安装和使用 Mishoo Chrome 插件。

Mishoo 是一个休息提醒插件。到休息时间时，一只小动物会走到当前网页上，挡住屏幕一会儿，提醒你离开电脑休息。

---

## 1. 使用前需要准备什么？

你需要：

1. 一台电脑。
2. Chrome 浏览器。
3. Mishoo 插件安装包，或 Chrome Web Store 上的 Mishoo 插件页面。

当前阶段如果 Mishoo 还没有正式上架 Chrome Web Store，普通测试用户需要从开发者那里获取插件压缩包。

---

## 2. 普通用户怎么获取插件？

### 方式一：正式上架后，从 Chrome Web Store 获取

如果 Mishoo 已经正式发布，推荐使用这种方式。

操作步骤：

1. 打开 Chrome 浏览器。
2. 进入 Chrome Web Store。
3. 搜索：`Mishoo` 或 `咪咻`。
4. 点击插件详情页。
5. 点击 **Add to Chrome / 添加至 Chrome**。
6. 浏览器弹出确认窗口后，点击 **Add extension / 添加扩展程序**。
7. 安装完成后，Chrome 右上角会出现 Mishoo 插件图标。

这种方式最适合普通用户，不需要打开开发者模式，也不需要手动解压文件。

---

### 方式二：内测阶段，从开发者提供的 zip 包获取

如果 Mishoo 还没有上架 Chrome Web Store，开发者会提供一个插件压缩包，例如：

```text
mishoo-chrome-extension.zip
```

普通用户需要先解压，再手动加载插件。

> 注意：Chrome 通常不能直接双击 zip 安装未上架插件。需要先解压，再通过 Chrome 的“加载已解压的扩展程序”安装。

#### 第一步：解压插件包

1. 找到开发者发给你的文件：

```text
mishoo-chrome-extension.zip
```

2. 右键这个文件。
3. 选择 **解压 / Extract / Unzip**。
4. 解压后会得到一个文件夹。

这个文件夹里应该能看到类似这些文件：

```text
manifest.json
extension/
assets/
videos/
```

如果你打开文件夹后没有看到 `manifest.json`，说明你可能多套了一层文件夹。安装时要选择真正包含 `manifest.json` 的那一层文件夹。

#### 第二步：打开 Chrome 扩展管理页面

在 Chrome 地址栏输入：

```text
chrome://extensions
```

然后按回车。

#### 第三步：打开开发者模式

在扩展管理页面右上角，打开：

```text
Developer mode / 开发者模式
```

#### 第四步：加载插件文件夹

1. 点击左上角或页面上方的：

```text
Load unpacked / 加载已解压的扩展程序
```

2. 选择刚才解压出来的 Mishoo 插件文件夹。
3. 确认后，Chrome 会加载 Mishoo 插件。
4. 页面中出现 **Mishoo / 咪咻** 插件卡片，就说明安装成功。

#### 第五步：固定插件图标

为了方便使用，建议把插件固定在 Chrome 工具栏上。

1. 点击 Chrome 右上角的拼图图标。
2. 找到 **Mishoo / 咪咻**。
3. 点击旁边的图钉按钮。
4. 固定后，Chrome 右上角会一直显示 Mishoo 图标。

---

## 3. 如何使用 Mishoo？

### 第一步：打开一个普通网页

Mishoo 会出现在“当前网页”上，所以你需要先打开一个普通网站，例如：

```text
https://github.com
https://www.wikipedia.org
https://news.ycombinator.com
```

也可以是你平时工作的网页、公司后台、文档页面等。

请注意，Mishoo 不能出现在 Chrome 自己的系统页面上，例如：

```text
chrome://extensions
chrome://settings
chrome://newtab
Chrome Web Store 页面
```

这是 Chrome 浏览器的安全限制，不是 Mishoo 故障。

---

### 第二步：打开 Mishoo 插件面板

1. 点击 Chrome 右上角的 Mishoo 图标。
2. 会弹出 Mishoo 设置面板。

你可以在面板里看到：

- 工作时长
- 休息时长
- 宠物选择
- Pawse Mode 开关
- 开始专注计时按钮
- 立即召唤按钮
- 休息统计

---

### 第三步：立即召唤小动物

如果你想马上测试效果：

1. 打开一个普通网页。
2. 点击 Chrome 右上角 Mishoo 图标。
3. 点击：

```text
立即召唤到当前网页
```

然后小动物会出现在当前网页上。

小动物出现后：

- 网页内容仍然在下面。
- 小动物会覆盖在页面上方。
- 左上角会显示休息倒计时。
- 右上角有退出按钮。

---

### 第四步：设置工作和休息时间

在 Mishoo 插件面板里可以设置：

```text
工作时长
休息时长
```

例如：

- 工作 50 分钟
- 休息 5 分钟

设置后，点击：

```text
开始专注计时
```

Mishoo 会在工作时间结束后自动出现在你当前正在使用的网页上，提醒你休息。

---

### 第五步：选择小动物

在插件面板里可以选择不同宠物，例如：

- 真实小猫 Mia
- 金毛 Cocoa
- 萨摩耶 Snow
- 博美 Mochi
- 垂耳兔 Mocha

选择后，下次召唤或计时结束时，会显示你选择的小动物。

---

### 第六步：使用 Pawse Mode

Mishoo 有一个选项：

```text
Pawse Mode：休息时拦截网页操作
```

开启后，在休息倒计时期间，Mishoo 会尽量拦截当前网页里的键盘操作，帮助你不要继续工作。

但它不会锁死整台电脑，也不会拦截操作系统级快捷键。你仍然可以通过右上角按钮退出休息遮罩。

---

## 4. 休息时怎么退出？

小动物出现后，右上角会有一个退出按钮。

如果休息时间还没有结束，按钮文案类似：

```text
现在退出休息
```

点击后可以提前退出。

如果休息时间已经完成，按钮文案会变成类似：

```text
回到网页
```

点击后可以正常回到网页。

---

## 5. Mishoo 可以在哪些页面使用？

### 可以使用的页面

Mishoo 可以在大多数普通网页使用，例如：

```text
普通网站
新闻网站
公司后台
在线文档网页
GitHub
Notion 网页版
各种 http:// 或 https:// 页面
```

### 不能使用的页面

Mishoo 不能在以下页面使用：

```text
chrome:// 开头的页面
Chrome 设置页
Chrome 扩展管理页
Chrome 新标签页
Chrome Web Store
部分浏览器内置 PDF 页面
部分浏览器安全页面
```

原因是 Chrome 不允许插件向这些页面注入内容。

如果你在这些页面点击“立即召唤”，可能会看到提示：

```text
请打开一个普通网页后再召唤咪咻。Chrome 内置页面无法注入宠物。
```

解决方法：打开一个普通网站后再使用 Mishoo。

## 6. 常见问题

### 问题 1：点击“立即召唤”后没有反应

请按顺序检查：

1. 当前页面是不是普通网页？
   - 如果是 `chrome://` 页面，请换到普通网站。
2. 插件是否安装成功？
   - 打开 `chrome://extensions`，确认 Mishoo 插件已启用。
3. 是否刚刚重新加载过插件？
   - 刷新当前网页后再试一次。
4. 是否在 Chrome Web Store 页面？
   - Chrome Web Store 不允许插件注入，请换一个网页。

---

### 问题 2：插件安装时提示无法加载

请检查你选择的文件夹是否正确。

正确的文件夹里应该直接包含：

```text
manifest.json
```

如果你选择的是外层文件夹，Chrome 可能找不到 `manifest.json`。

解决方法：进入下一层文件夹，选择真正包含 `manifest.json` 的文件夹。

---

### 问题 3：插件图标找不到

可能是没有固定到工具栏。

解决方法：

1. 点击 Chrome 右上角拼图图标。
2. 找到 **Mishoo / 咪咻**。
3. 点击图钉按钮。

---

### 问题 4：小动物没有出现在某些网页

有些网页会限制脚本注入，或者页面本身比较特殊。

你可以先用这些网站测试：

```text
https://www.wikipedia.org
https://github.com
https://news.ycombinator.com
```

如果这些网站可以显示，说明插件本身是正常的。

---

### 问题 5：小动物挡住页面了，怎么退出？

点击右上角的退出按钮即可。

Mishoo 当前版本始终保留明显的退出按钮，不会锁死屏幕。

---

## 7. 插件权限说明

Mishoo 需要一些 Chrome 权限才能正常工作。

### `storage`

用于保存你的设置，例如：

- 工作时长
- 休息时长
- 选择的小动物
- 语言
- 休息统计

这些数据保存在本地浏览器里。

### `alarms`

用于在工作时间结束后触发休息提醒。

### `tabs`

用于找到当前正在使用的网页，把小动物显示到这个网页上。

### `scripting`

用于在当前网页没有加载 Mishoo 脚本时，动态注入一次脚本。

### `<all_urls>`

用于让 Mishoo 可以在不同普通网页上出现，而不是只能在一个固定网站里使用。

Mishoo 当前版本不会读取摄像头，不会录屏，不会上传你的网页内容。

---

## 8. 卸载 Mishoo

如果你不想继续使用：

1. 打开：

```text
chrome://extensions
```

2. 找到 **Mishoo / 咪咻**。
3. 点击 **Remove / 移除**。
4. 确认移除。

---

## 9. 推荐给测试用户的最短使用流程

如果你只是想快速体验，可以按这个流程：

1. 从开发者那里拿到 `mishoo-chrome-extension.zip`。
2. 解压 zip。
3. 打开 Chrome：`chrome://extensions`。
4. 开启开发者模式。
5. 点击“加载已解压的扩展程序”。
6. 选择包含 `manifest.json` 的 Mishoo 文件夹。
7. 打开一个普通网页，例如 `https://www.wikipedia.org`。
8. 点击 Chrome 右上角 Mishoo 图标。
9. 点击“立即召唤到当前网页”。
10. 看到小动物出现，就安装和使用成功了。
